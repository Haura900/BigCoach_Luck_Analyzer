# BigCoach Luck Analyzer

BigCoachの解析JSONから、技術に依存しにくい8つの運量と牌山の偏りを検証する静的Webアプリです。

公開版: <https://haura900.github.io/BigCoach_Luck_Analyzer/>

## 使い方

通常は画面上部の「ふだんは、こちらだけ使います」に従います。

1. BigCoachの履歴に表示されるプレイヤー名を入力します。
2. 生成された「未取得実戦を保存」をブックマークバーへドラッグします。
3. ログイン済みBigCoachの `https://gokujan.com/account/history` でそのブックマークを実行します。
4. ダウンロードされた差分JSONをLuck Analyzerへ読み込みます。

初回は対象プレイヤーの過去の実戦牌譜、次回以降は未取得分だけを保存します。取得済みタスクIDはBigCoach側オリジンの `localStorage` に、解析結果はLuck Analyzer側の `localStorage` に保存されます。

単局取得、URL、JSON貼り付けは「1局だけ取り込む／手動で取り込む」の中にあります。

## 指標と検定

経験分布で評価:

- 配牌時和了率
- 配牌時平着変動
- 放銃予実幅

残り牌から逐次理論値を計算:

- ドラツモ率
- 有効牌ツモ率
- リーチ時自明和了率
- リーチ時危険牌率
- 被リーチ時現物掴み率

主検定は「理論値系」「BigCoach依存系」「全指標統合」の3通りです。系統内のp値をCauchy法で統合し、3主検定をHolm法で補正します。全指標統合は両系統のp値が揃った場合だけ実施します。

総合運と4系統の累積推移をグラフ表示し、取り込み履歴には取得できた対戦相手、対局種別、卓名、プラットフォームを表示します。

## 注意点

- p値は牌操作がある確率ではありません。
- 経験分布は、このブラウザに保存した自分の履歴を母集団にします。
- BigCoach JSONでは未配牌の生牌山と未公開の王牌を分離できないため、理論確率の母集団には未公開王牌を含みます。
- 対戦相手などのメタデータがJSONにない場合は「情報なし」と表示します。
