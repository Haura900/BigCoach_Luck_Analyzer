# BigCoach Luck Analyzer

BigCoachの解析JSONから、自分と他家の技術に依存しにくい29の運量と牌山の偏りを検証する静的Webアプリです。

公開版: <https://haura900.github.io/BigCoach_Luck_Analyzer/>

## 使い方

通常は画面上部の「ふだんは、こちらだけ使います」に従います。

1. BigCoachの履歴に表示されるプレイヤー名を入力します。
2. 生成された「未取得実戦を保存」をブックマークバーへドラッグします。
3. ログイン済みBigCoachの `https://gokujan.com/account/history` でそのブックマークを実行します。
4. ダウンロードされた差分JSONをLuck Analyzerへ読み込みます。

初回は対象プレイヤーの過去の実戦牌譜、次回以降は未取得分だけを保存します。取得済みタスクIDはBigCoach側オリジンの `localStorage` に保存します。Luck Analyzer側では、元の巨大JSONを保持せず、29指標・実着順・履歴表示に必要な解析後データと集計キャッシュだけをIndexedDBへ保存します。同じタスクID・同じ計算版は再解析しません。

単局取得、URL、JSON貼り付けは「1局だけ取り込む／手動で取り込む」の中にあります。

## 指標と検定

経験分布で評価:

- 配牌時和了率
- 配牌時平着変動
- 放銃予実幅

残り牌から逐次理論値を計算:

- ドラツモ率
- 有効牌ツモ率
- 2シャンテン時有効牌ツモ率
- 1シャンテン時有効牌ツモ率
- リーチ時自明和了率
- リーチ後危険牌回避度
- 被リーチ時現物掴み率
- 被リーチ・1シャンテン時現物掴み率
- 被リーチ・聴牌時現物掴み率
- 被副露時現物掴み率
- 被副露・1シャンテン時現物掴み率
- 被副露・聴牌時現物掴み率
- 無駄ツモ率（幸運度は少ないほど高い）
- テンパイ到達ツモ
- テンパイ後和了牌ツモ
- リーチ時他家掴ませ率
- 配牌時ドラ枚数
- 配牌時役牌対子・暗刻数
- 自分裏ドラ運
- 他家配牌ドラ回避
- 他家ドラツモ回避
- 他家テンパイ到達回避
- 他家和了牌ツモ回避
- 他家リーチ和了回避
- 他家裏ドラ回避

局開始時のBigCoach 5結果予測と実現結果のうち、自分の手組・押し引きが比較的入りにくいものを経験分布で評価:

- 他家決着回避上振れ

主検定は「理論値系」「BigCoach依存系」「全指標統合」の3通りです。系統内のp値をCauchy法で統合し、3主検定をHolm法で補正します。全指標統合は両系統のp値が揃った場合だけ実施します。

各幸運度は、理論値系では標準化差へ分布関数を適用し、経験分布系では経験累積分布を使った `U ∈ [0,1]` です。これは上振れ方向の累積確率であり、両側p値は `2 min(U, 1-U)` として別に表示します。

総合運は、29指標の向きをすべて「自分にとって幸運」へ揃え、1半荘を1行とするL2正則化付き非負回帰で `5 − 最終着順` を推定します。対象機会がない指標は `U=0.5` で補完し、加重点を半荘ごとの同時経験累積分布へ通した値を総合運の `U ∈ [0,1]` とします。1シャンテン有効牌とテンパイ到達など指標間に重複・相関があるため、独立な一様分布を仮定した理論CDFは使いません。係数・対象半荘数・学習内相関に加え、未知半荘への当てはまりを過大評価しないよう5分割検証相関も画面に表示します。最終着順と最終点棒は教師データにだけ使い、運指標の入力には使いません。

推移グラフは半荘単位で、直近50半荘を初期表示し、25・50・100・全半荘を選択できます。実着順、総合運、29指標を個別にオン・オフでき、初期状態では実着順・総合運・重み上位5指標を表示します。実着順は1着=1、2着=2/3、3着=1/3、4着=0として半荘ごとに破線表示するだけで、運指標には混ぜません。取り込み履歴には取得できた対戦相手、実着順、対局種別、卓名、プラットフォームを表示します。

## 注意点

- p値は牌操作がある確率ではありません。
- 経験分布は、このブラウザに保存した自分の履歴を母集団にします。
- BigCoach JSONでは未配牌の生牌山と未公開の王牌を分離できないため、理論確率の母集団には未公開王牌を含みます。
- リーチ後危険牌回避度は相手の構造的な待ちを使います。相手の捨て牌によるフリテンは除外しますが、役と一時フリテンは判定していません。
- リーチしていないテンパイの和了牌指標は、牌の到来だけを測り、役の有無と一時フリテンは判定していません。
- 相関は因果関係や「順位の何%が運か」を表しません。特に学習内相関は高めに出るため、予測力の目安には5分割検証相関を使います。
- 対戦相手などのメタデータがJSONにない場合は「情報なし」と表示します。
